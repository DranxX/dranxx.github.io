How we work

From brief to implementation

Before I write any code, we agree on what to build and how to check that it works. The handover follows that agreement.

Describe the feature

Send the goal, an example flow, the platform, and any existing code. For a bug, include the steps to reproduce it.

Agree on scope

We list the work, dependencies, priorities, timeline, and what counts as done, so nothing is left to assumption.

Build & check the flow

I build and integrate the feature, then test how it handles normal use, cancellations, bad input, and disconnects.

Hand over with context

You get the source code, integration steps, configuration notes, test results, and any limits that remain.
