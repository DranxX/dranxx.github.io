# Portfolio fonts

Barlow Condensed (300, 400, 500, 600, 700, 800) and IBM Plex Mono (300, 400, 500) are the existing portfolio typefaces. The Google Fonts CSS and its font files are hosted here so rendering does not require Google Fonts at runtime. The original unicode ranges and `font-display: swap` are retained.

Source: https://fonts.google.com/
